# Fotos do site

Solte os arquivos aqui com estes nomes exatos. Cada foto substitui
automaticamente a ilustração correspondente; o que não existir continua
mostrando o desenho em SVG, sem quebrar nada.

| Arquivo             | Onde aparece                         | Proporção sugerida |
|---------------------|--------------------------------------|--------------------|
| `hero.jpg`          | Bloco do topo, ao lado do título     | 4:3 (paisagem)     |
| `lanai.jpg`         | Galeria — lanai e área de piscina    | 4:3                |
| `living-room.jpg`   | Galeria — sala / home theater        | 4:3                |
| `game-room.jpg`     | Galeria — sala de jogos              | 4:3                |
| `video-wall.jpg`    | Galeria — video wall / recepção      | 4:3                |
| `signage.jpg`       | Galeria — fachada / menu board       | 4:3                |
| `mount-detail.jpg`  | Galeria — detalhe do suporte         | 4:3                |

Dicas:
- Largura de 1600 px já basta; acima disso só pesa a página.
- Exporte em JPG com qualidade ~80 e, de preferência, abaixo de 400 KB.
- Foto de instalação sua vale mais que qualquer banco de imagem: mostra o
  acabamento, o cabo escondido e o ambiente real.
- Se usar foto de banco de imagem, use só licença livre para uso comercial
  (Unsplash, Pexels, Pixabay) e guarde o link da origem.
